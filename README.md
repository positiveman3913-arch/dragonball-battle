# 드래곤볼 배틀 리메이크

기존 공개 게임의 화면 흐름과 기본 행동 체계를 참고해 새로 만든 별도 프로젝트입니다.

## 구현 기능
- 방 생성 및 6자리 초대 코드
- 같은 방 플레이어 목록 및 호스트 권한
- 원작 공개 룰에 기반한 동시 선택 라운드
- 기력 5개를 모으면 원기옥 사용 가능
- 원기옥은 방 안의 다른 모든 생존 플레이어를 즉시 탈락시킴 (방어/회피 불가)
- Socket.IO 기반 실시간 채팅
- 모바일 대응 레이아웃

## 실행
Node.js 18 이상 필요.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

## Render 배포
1. 이 프로젝트를 GitHub 저장소에 올립니다.
2. Render에서 New > Web Service를 선택하고 저장소를 연결합니다.
3. Runtime은 Node, Build Command는 `npm install`, Start Command는 `npm start`로 설정합니다.
4. 배포 후 생성된 URL을 친구들과 공유합니다.

## 주의
- 이 버전은 별도 서버에서 동작하는 신규 구현이며 기존 dragonball-game.onrender.com 서버를 수정하지 않습니다.
- 방 데이터는 서버 메모리에 저장됩니다. 서버가 재시작되면 방과 채팅 기록이 사라집니다.
- 단일 서버 인스턴스 기준입니다. 다중 인스턴스 확장 시 Socket.IO 어댑터와 공유 저장소가 필요합니다.
- 현재 구현은 프로토타입입니다. 실제 공개 운영 전 재접속 처리, 속도 제한, 채팅 신고/차단, 방 만료 정책, 테스트를 추가하는 것을 권장합니다.
